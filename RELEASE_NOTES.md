# Beako Presence — versões definitivas

Esta release reúne as **versões oficiais fornecidas pelo autor**, sem alterações no código dos aplicativos.

## Windows 3.6.1

Baixe `Beako-Presence-Windows-3.6.1.zip`, extraia toda a pasta e execute `BeakoPresence.exe`.
O pacote inclui EXE, código-fonte, ícones, imagem e catálogo offline. Requer Windows com .NET Framework 4.8.

O arquivo `BeakoPresence-Windows-3.6.1.exe` também está disponível separadamente, mas **o ZIP completo é recomendado** para manter os recursos e o catálogo offline.

## Linux 3.7.3

Baixe `Beako-Presence-Linux-3.7.3.zip`, extraia em uma pasta e execute:

```bash
bash ./instalar.sh
```

Requer Python 3.9+, Tkinter e Bash. O ZIP inclui arquivos de configuração, ícones e catálogo offline.

## Integridade

O arquivo `SHA256SUMS.txt` contém os hashes SHA-256 dos downloads.

O reconhecimento dos processos como jogos depende da detecção do Discord e não é garantido para todos os títulos.
